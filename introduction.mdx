# LLMO

**Large Language Model Optimization** (LLMO) is a protocol for making entities, claims, and operational truth legible, trustworthy, and actionable inside machine reasoning systems.

This document specifies LLMO v0.1.0.

## Definition

LLMO optimizes the full semantic presence of an entity across retrieval, generation, memory, and execution layers. It subsumes prior optimization disciplines (SEO, AEO, GEO) by extending the optimization target from pages and answers to the complete machine-legible truth surface.

## Motivation

The internet was built for human browsing. The emerging machine layer is built for model interpretation. This shift changes the optimization surface.

Entities operating in AI-mediated environments must now optimize for:

- Model retrieval and citation
- Answer inclusion and model preference
- Factual compression and semantic consistency
- Memory persistence across AI systems
- Downstream machine action

An entity can be highly visible to humans and simultaneously invisible, distorted, or misrepresented inside LLM-mediated environments.

---

## Problem statement

Organizations exist in two realities: **external perception** and **internal precision**.

External perception is how machine systems represent an entity. Internal precision is whether the entity possesses the truth, structure, and data integrity necessary to support that representation.

Failure typically occurs because one is optimized without the other. LLMO binds the two.

## Non-goals

LLMO is not a synonym for SEO, AEO, or GEO. It is not prompt engineering. It is not a wrapper around any specific model provider. It is not an analytics product. It is not content marketing.

---

## Machine-facing identity

Every entity is developing a machine-facing identity whether it intends to or not. This identity is assembled from websites, documentation, reviews, press, directories, structured data, third-party mentions, knowledge graph fragments, model training residues, and live retrieval layers.

LLMO is the discipline of governing that identity.
