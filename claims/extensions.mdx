# Extensions

<Info>
Registry submission is not yet open. This page describes how extension claim types work; submissions will be accepted once the registry's governance model is formalized.
</Info>

The extension registry opens in a future phase. Extension claim types use the format `namespace.type` (for example, `acme-corp.compliance_note`). The `namespace` SHOULD be a short identifier the publisher controls, ideally matching a domain they own.

Publishers may define extensions without registering them. A publisher can emit a claim with any well-formed namespaced type, and conforming consumers will ignore types they do not understand (specification [§3.6](/spec/v0.1#3-6-extension-claims)). The registry exists for discoverability of widely-adopted extensions — not as a gate on usage.

Mature extensions may be promoted into the core set in a future specification version. Governance for promotion is an open question (specification [§8.5](/spec/v0.1#8-open-questions-for-v0-2)).
