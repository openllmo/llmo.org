# Humans + Harness

Humans + Harness is the operating doctrine for production-grade machine-enabled execution.

The doctrine rejects both extremes: unaugmented human labor, and autonomous AI without control.

## Rationale

LLMs are fluent but unstable. They produce confident output regardless of underlying reasoning quality. They hallucinate, drift, and compress ambiguity into false precision.

Humans are accurate in specific contexts but expensive, inconsistent, and slow. They possess domain expertise but cannot scale.

Neither is sufficient alone for high-stakes production work. The harness is the structural element that converts ad hoc human-AI interaction into a governed operating model.

## Harness specification

The harness is the deterministic layer around stochastic models.

| Function | Description |
|---|---|
| **Task decomposition** | Breaking work into bounded, verifiable units |
| **Routing** | Directing tasks to the appropriate agent, model, or human |
| **Retries** | Re-executing failed steps with logged state |
| **Confidence handling** | Escalating when model confidence falls below threshold |
| **Evaluation** | Checking outputs against ground truth or acceptance criteria |
| **Policy checks** | Enforcing domain-specific rules before output acceptance |
| **Memory calls** | Retrieving relevant context from structured stores |
| **Audit logs** | Recording every decision, input, output, and state transition |
| **Provenance capture** | Tracking the source chain for every claim used in reasoning |
| **State transitions** | Managing workflow progression through defined stages |
| **Escalation** | Routing edge cases and high-risk decisions to human reviewers |
| **Refusal pathways** | Declining output when available truth is insufficient |
| **Replayability** | Re-executing workflows from logged state for audit or debugging |

## Human role specification

Humans operate at the constitutional and judgment layer:

- Validate edge cases outside model training distribution
- Resolve ambiguity that models would compress into false precision
- Approve sensitive actions with real-world consequences
- Detect and correct epistemic drift
- Maintain policy quality and update constraints
- Label data for evaluation
- Supervise failed retries
- Make irreversible decisions
- Serve as accountable operators in high-risk domains

The harness does not replace human judgment. It concentrates judgment where it produces the most value.

## Relationship to LLMO

Optimization ensures accurate external representation. Operations ensures internal truth is machine-usable. Humans + Harness ensures the execution layer is controlled, auditable, and accountable.

Without this doctrine, LLMO's optimization and operations layers lack an execution mechanism.

## The refusal principle

A well-designed system must sometimes refuse, escalate, or defer rather than produce confident but incorrect output.

A refusal state is a legitimate system output. It indicates that the harness determined available truth was insufficient to produce a verified decision within the required error bound and risk tier. Truth integrity takes precedence over output volume.
