# Contact

- **GitHub repository:** [github.com/openllmo/llmo.org](https://github.com/openllmo/llmo.org)
- **Issue tracker:** [github.com/openllmo/llmo.org/issues](https://github.com/openllmo/llmo.org/issues)
- **Spec feedback:** [spec@llmo.org](mailto:spec@llmo.org)

For specification issues, proposed changes, and general feedback on the protocol, open an issue on the GitHub repository or email the address above. Include a clear statement of the issue or proposal; reference specific sections of the specification where applicable.
