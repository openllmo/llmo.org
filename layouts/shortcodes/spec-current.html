{{- /* spec-current: emits the latest released spec version and its publication date, sourced from content/spec/changelog.md. Single source of truth: scripts/cut-release.sh mutates the changelog, this shortcode reads it, /spec landing page renders it. No second place to update on release. Modes (positional arg): {{< spec-current >}} -> "v0.1.10, published 2026-05-19" {{< spec-current "version" >}} -> "v0.1.10" {{< spec-current "date" >}} -> "2026-05-19" Matches the first `## [X.Y.Z] - YYYY-MM-DD` header in the changelog. The Keep-a-Changelog format puts the latest release immediately after the `## [Unreleased]` placeholder, so first-match is correct. */ -}} {{- $mode := .Get 0 | default "full" -}} {{- $changelog := readFile "content/spec/changelog.md" -}} {{- $headers := findRE `## \[[0-9]+\.[0-9]+\.[0-9]+\] - [0-9]{4}-[0-9]{2}-[0-9]{2}` $changelog 1 -}} {{- if not $headers -}} {{- errorf "spec-current: no `## [X.Y.Z] - YYYY-MM-DD` header found in content/spec/changelog.md" -}} {{- end -}} {{- $header := index $headers 0 -}} {{- $version := index (findRE `[0-9]+\.[0-9]+\.[0-9]+` $header 1) 0 -}} {{- $date := index (findRE `[0-9]{4}-[0-9]{2}-[0-9]{2}` $header 1) 0 -}} {{- if eq $mode "version" -}} v{{ $version }} {{- else if eq $mode "date" -}} {{ $date }} {{- else -}} v{{ $version }}, published {{ $date }} {{- end -}}
