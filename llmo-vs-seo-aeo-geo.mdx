# LLMO vs SEO, AEO, and GEO

## SEO: Search Engine Optimization

Optimizes page ranking in traditional search engines through crawlability, authority, link structure, technical health, and keyword relevance. Assumes a human user visits the ranked page.

- **Unit:** page
- **Metric:** traffic
- **Target:** search engine crawlers and ranking algorithms

## AEO: Answer Engine Optimization

Optimizes for inclusion, citation, or summarization in answer engine responses. Assumes the user may never visit the source.

- **Unit:** answer
- **Metric:** citation, mention, or answer inclusion
- **Target:** answer generation systems

## GEO: Generative Engine Optimization

Optimizes how generative systems represent an entity, topic, or fact pattern. Subsumes AEO.

- **Unit:** representation
- **Metric:** favorable model synthesis
- **Target:** generative model behavior across retrieval and generation

## LLMO: Large Language Model Optimization

Subsumes SEO, AEO, and GEO. Optimizes the entire semantic presence and operational truth surface of an entity for machine reasoning systems.

- **Units:** entity, claim, fact, decision, actionable truth surface, verified decision unit
- **Metrics:** machine discoverability, machine legibility, machine preference, factual integrity, operational consistency, model memory coherence, trustworthiness under retrieval, actionability
- **Target:** the full machine reasoning layer, including retrieval, generation, memory, and execution

---

## Summary

| | SEO | AEO | GEO | LLMO |
|---|---|---|---|---|
| **Unit** | Page | Answer | Representation | Entity / Claim / Decision |
| **Scope** | Search ranking | Answer inclusion | Generative representation | Machine-legible reality |
| **Includes operations** | No | No | No | Yes |
| **Includes orchestration** | No | No | No | Yes |
| **Includes trust/verification** | No | No | No | Yes |

LLMO does not invalidate SEO, AEO, or GEO. It contains them. The distinction is that LLMO extends beyond representation into operations, orchestration, and trust. An entity with strong GEO but no internal truth infrastructure is optimizing a surface with nothing beneath it.
